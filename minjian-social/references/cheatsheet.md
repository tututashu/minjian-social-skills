# 决策规则速查 — 中国民间社交通用全书

| 能力 | 一句话规则 |
|---|---|
| 难处之人应对法（24 类识人应对） | 先按可观察行为识类（证据链：接触记录+侧证+观其待至亲），再取对等/防御/止损策略，恒守不受损、不结仇、不同流。 |
| 交谈技法与问答辞令 | 总纲"从容+措词"，八守则禁令清单护航，话题按对象素材库取、避开判定性隐私问题，纠错用建议+求问语气。 |
| 应酬礼仪程序（介绍·访谒·宴集·馈赠·称谓） | 礼数投入随关系深度与场景正式度定价，五环节各有定量规矩——回访时限、份子公价、等宾一刻钟、礼先期到、递利器柄朝人。 |
| 书信套语选用（提称·启事·疏候·思慕·恭维·具名·封缄） | 先定位关系五坐标（辈分×职业×性别×亲疏×场合），再逐段查七语类分级表；恭维幼对长必备、具名方向性选词、尊长不缀名。 |
| 红白仪式讲话体例 | 仪式讲话先定角色再定文体——主婚出训词、证婚出箴词、介绍出赠词、来宾出颂词（庄谐并重祝词收尾）、新人出答谢；白话必须映射真人真事。 |
| 丧仪文书体例（讣闻·祭文·诔词·悼词） | 丧仪文书是身份编码——孤子/哀子/孤哀子按父母存殁，寿终享年 vs 疾终存年按辈分，诔词"幼不诔长"有方向，护丧者代丧主接客。 |
| 柬帖体例（帖式解读与选用） | 帖式三层（类—式—槽位）+形制即敬意：请师长用全帖夹单帖、冥寿降等单帖、礼单是程序单不是礼品清单。 |
| 场合楹联选用法 | 选联=场合×身份二维查表——先落场合格（时令/处所/行业/喜庆/丧事/名胜），再落身份格（寿龄档/性别/职业/亲等关系）。 |
| 募捐与启事类应用文 | 劝募文书两要件——写实情立信、三层意义（对事/对众/对捐者）立动机，发起人具名担保、份金定在群体可负担水平。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。

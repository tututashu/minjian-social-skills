# 交谈技法与问答辞令（八守则 + 对象话题匹配）

## R — 原文

> "①不可（滔滔不绝），使对方没有应答的机会。……⑥谈话时，不宜批评第三者的私德。否则，对方会觉得你将来也可能批评他。他就不敢与你做朋友了。"（第一章·第三节 1，PDF 第 83–84 页）

> "谈话中如发觉对方有错误或悖理时，你不能直斥他的不是，而应该用建议的方式，很客气地提出你的意见，并且用求问的语调：'这样是不是会更能收到效果？'"（第一章·第一节 5，PDF 第 41 页）

## I — 自述

本书把交谈拆成"总纲—禁令—匹配"三层：

1. **总纲两词**：从容（不急不迫的安详态度）＋ 措词（含义准确而简练）。这是作者对"会说话"的正式定义。
2. **八守则**（以"不"句式为主的禁令清单）：不滔滔不绝剥夺对方应答；听人说话必双目注视倾耳细听；重大问题不随便允诺（可答"这事须要考虑一下"）；话题照顾对方的知识与兴趣；意见不合勿用凌厉词句驳诘；不批评不在场者的私德；大庭广众不打岔；也不默言冷坐。
3. **对象—话题匹配**：先判对方身份（年龄/性别/职业），再从对应素材库取话题——青年谈运动、商界谈其业务、学界以请教其著作为切入、主妇谈生活与孩子；同时避开该对象的判定性禁忌（对女性不问年龄婚否家庭、对初识者不"查家问宅"式连珠追问、对商界勿咬文嚼字）。
4. **纠错话术**：禁止直斥，换成建议形式＋求问语气落地；配套禁用"你从来也不/你总是/你根本"式绝对否定，幽默而非嘲笑。
5. **投射推演**：说话前预演"听者会如何推断我的行为模式"——批评不在场者＝向听者现场演示你如何议论人，听者会把自己代入未来的被议论者。

## A1 — 书中案例

1. **递烟破冰**（第一章·第三节问答辞令）：递烟→对方婉拒→顺势请教戒烟经验→互通姓名自然展开。示范"借对方感兴趣的小事开场"胜过直接查问姓名籍贯。
2. **向教授请教三步**（第一章·第三节）：先捧其著作（"大作拜读过，得益不少"）→自谦门外汉→提出具体请教点；对方谦辞后仍诚恳坚持，对方顺势另约时间。全程"只可请教、不可请难（考对方）"。
3. **久别重逢开场**（第一章·第三节）：以"常在某共同朋友处问及你"起头（既表挂念又得话头），再由近况→家人→共同熟人层层递进——借共同熟人开场的完整范本。

## A2 — 未来触发

**用户场景**：
- 第一次见某人（相亲对象家长、新同事、客户），不知道聊什么、怕说错话
- 想给对方提意见/纠错，怕伤和气
- 和人争执后想修复，或当场谈崩需要台阶
- 请教专家、求人办事前的话头准备
- 想吐槽某人，犹豫当着谁的面说

**语言信号**：'第一次见面聊什么'、'怎么开口请教'、'怎么提意见不伤人'、'冷场了怎么办'、'能不能吐槽'、small talk、conversation opener。

**与相邻能力区分**：判断"这个人值不值得深交、以什么姿态相处"→ U1；正式场合（婚礼/寿宴）的致辞体例 → U5；本卡管一对一交谈的全程技术。

## E — 执行步骤

1. **对象归类**：对方年龄/职业/与我的关系层级。完成标准：能选出对应的话题素材库与禁忌清单。
2. **选题**：从素材库取 2–3 个安全话题，避开该对象的判定性问题。完成标准：话题不涉及对方隐私判定（年龄/婚否/收入/家庭底细类）。
3. **开场**：用"对方感兴趣的小事/共同熟人/对方成就"起头，不查户口式提问。
4. **过程自检**（每轮对照八守则）：是否留了应答空间？是否在批评不在场者？重大请求是否轻诺？
5. **纠错**（如需）：直斥→改写为"建议＋求问语气"，删掉绝对化措辞。完成标准：草稿中无"你从来/你总是/你根本"。
6. **收尾**：留好下次联系的话头（书中：告辞说"改日再来拜候"式的话）。

## B — 边界

- **不是话术操纵**：八守则的机制是尊重对方的注意力与自尊，不是控制对方；拒绝把本卡用于 PUA 式引导。
- **禁忌清单的时代注**：对女性的三忌（年龄/婚否/家庭）机制——"判定性隐私问题即冒犯"——仍然有效，但话题库（电影/游泳）应换成当代素材。
- **别当万能模板**：素材库匹配是起点不是剧本，书中明言"怎样运用，那就由你随机应变"。
- **相邻易混**：谈判、销售类专业话术不在本卡范围；涉及利益冲突的正式谈判另用专业方法。
